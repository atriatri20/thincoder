aliases: 最近改动, 改过哪些档
- Tracked tools: write / edit / insert_after / apply_patch / delete / hashline_edit.
- Use it when you need to remember which files you have already touched; during long multi-file tasks it is easy to lose track.
- Scoped to this run only, unlike `git status`, which shows all uncommitted changes.

For session-level history (what was said in a session), use read_history.
