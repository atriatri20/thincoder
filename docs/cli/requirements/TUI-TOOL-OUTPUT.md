# TUI 工具输出 · 需求

> 设计 = `docs/cli/design/TUI-TOOL-OUTPUT.md`。

## 1. 功能

- **FR1**：每个普通工具调用有唯一行间区块，标题含工具名与可读参数摘要。
- **FR2**：执行中通过当前 onToolOutput 通道增量显示最近内容，超出有省略标记。
- **FR3**：完成时显示 done、耗时与成功/失败摘要，不遗留执行中块。
- **FR4**：区块只是预览；完整工具结果按 core 当前 history/输出规则保存，模型不依赖 UI 预览。

## 2. 非功能

- **NFR1**：流式追加走当前增量渲染，不无条件全屏重绘。
- **NFR2**：普通输出经统一入口；对象 chunk 与字符串 chunk 按当前契约兼容。

## 3. 边界

不另建工具面板区；子代理和 advisor 使用各自活动块；参数全量显示遵循 TUI 无悬停规则。
