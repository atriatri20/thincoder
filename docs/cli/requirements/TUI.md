# TUI（终端界面）· 需求

> 设计 = `docs/cli/design/TUI.md`、`TUI-INPUT-BOX.md`、`TUI-SESSION-VIEW.md`、`TUI-COMMANDS.md`、`TUI-TOOL-OUTPUT.md`。

## 1. 会话与滚动

- **F1–F4**：新输出默认跟随尾部；上滚暂停；暂停和加载旧页时保持当前阅读锚；回底或新提交恢复跟随。
- **F5**：PgUp/PgDn 与滚轮负责会话滚动，↑↓ 只负责输入框。
- **F6–F7**：恢复只物化最新首页，到顶按 TUI 旧页步长懒加载；首页与旧页预算是两个独立边界。顶部显示剩余条数，磁盘会话记录是数据源，跨页读取保留前后配对边沿但不重复渲染。
- **F8**：子代理嵌套活动进入所属块 tail，展开后可读全量，不重复占位。

## 2. 选择与输入

- **F9**：picker 的 note 与 provider 不可用警示可见，窄终端按当前宽度规则处理。
- **F10**：question、wizard、picker 保留职责；同义键、环绕和选中项可见按当前契约。
- **F11**：主输入支持多行竖移、显示列保持、历史导航与草稿恢复；Inject 框支持四方向编辑。processing 时允许纯编辑，不允许历史切换。
- **F12**：`/advisor` 子菜单能打开；showPicker entries 必须已解析为数组，Promise 输入给明确错误。

## 3. 状态与命令

- **F13**：审批、提问和回合结束等待输入时显示 attention；用户输入或条件消除后复位。普通 processing、用户主动 picker 等不误报。
- **F14**：provider 与 MCP 删除在落盘前显式确认；取消零写零内存变更；缺确认能力时失败而不是直删。
- **F15**：状态行按当前布局常显非空会话标题，超宽截断。
- **F19**：首启向导提供本地 provider 与团队登录两路；失败给可读原因并允许改选。
- **F20**：团队已登录时状态行显示当前成员与服务器摘要，未登录不伪造该段。
- **F21**：`/minimal`、`/normal`、`/eng` 操作同一互斥会话 mode。`/minimal` 在 minimal 与 normal 间切换；`/eng` 在 engineering 与 normal 间切换；`/normal` 始终进入 normal。切换立即持久化，下一轮提示词生效。

## 4. 队列、timer 与恢复

- **F16**：busy 时普通文本进入有界队列，待发送内容可见；步边界优先消费，回合尾和挂起 driver 兜底。连续普通文本在条数与格式化字符双预算内合并，斜杠命令、超长单条和携图条目不跨条合并；队满拒绝且保留文本。Ctrl+I 仍是独立中断通道。
- **F17**：在途、到期与触发 timer 可见；状态行、`/timers` 与落流行使用当前形态，无在途不占位。
- **F18**：digest 痕与 subagent 归档块按会话记录重启重建；在飞活动不伪造成冻结历史。

## 5. 非功能

- **N1–N3**：缓存使加载和重绘不随已加载历史线性恶化；页大小与当前跨端契约一致。
- **N4–N7**：零额外 UI 依赖；折叠行数、省略计数和 picker 宽度真实有界。
- **N8**：竖移按显示列，CJK/emoji 不劈半。
- **N9**：attention 是状态派生，不新增空闲定时器。
- **N10–N11**：行、工具结果、子块、评审、流式缓冲和 `state.lines` 有当前字符/行数双维预算；裁减保留保底可见行，增删账一致。
- **N12**：启动与纯信息命令不随 sessions/traces 存量线性阻塞，按 core 当前启动预算验证。

## 6. 边界

不做完整鼠标 UI、系统通知或终端标题提醒；不合并三种选择面实现；不以显示截断改变会话全史。
