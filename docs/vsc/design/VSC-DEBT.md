# VSC 结构与验证规则 · 设计

> 判据 = `docs/core/standards/CODE-TIER.md`、`docs/core/design/TESTING.md`；协议 = `WEBVIEW-PROTOCOL.md`。

## 1. 慢例与档位

慢例按当前 VSC 测试归册规则逐例测量；例名正则转义并确认恰好选择一例。满载偶发慢不直接证明单例应归册，需复跑。

源码档位只在 CODE-TIER 指定时点实读。拆分时保持导出名、re-export、调用点和既有测试，不把历史行数写成永久状态。

## 2. 协议覆盖

协议枚举使用 host→webview 顶级 type/name；载荷内 status/kind 不作为新的顶级消息。辅助发射点要追到载荷构造处。

每个标识符记录发射与消费。缺消费者或缺生产者必须显式处置，不能用注释宣称已覆盖。删除死码后检查真实引用。

## 3. 当前验证边界

本档不保存已完成的拆分、删除或测试清单。未运行、未覆盖或待用户决定的缺口只在相应验证报告与最终治理结果中如实列出。
