# VSC Webview · 需求

> 设计 = `docs/vsc/design/WEBVIEW.md`、`WEBVIEW-INPUT.md`、`WEBVIEW-PROTOCOL.md`。

## 1. 布局、滚动与历史

- **F-W1**：会话栏、消息区、活动区、goal/task 面板、输入区按当前垂直布局。live 活动块驻留，消化后同形归档入流；digest/subagent 记录可重建。
- **F-W2**：消息区默认跟尾；向上滚动立即解钉，600ms 内续期，到期按半视口且至少 24px 的近底阈恢复；回底有明确出口。活动块独立跟滚。
- **F-W3**：首窗与旧页使用 core 页大小 200 条，scrollTop ≤ 40 近顶加载，prepend 保持视口锚，hasOlder=false 不请求。

## 2. 工具与输入

- **F-W4**：工具卡显示名称、参数摘要、流式输出、完成耗时和摘要；成功折叠、失败展开；卡体上限 64 × 1024 字符并附截断标记，全文在会话记录。
- **F-W5**：Enter 发送；IME 与 @ 下拉优先；无工作区拒发并提示；busy 按容量 8 受理，满队拒绝并保留文本。
- **F-W6**：↑↓ 按 IME、@、历史、单行、多行边界五态处理，草稿可恢复，不破坏原生竖移。
- **F-W22**：busy 待发送带位于输入区上方，不提前在消息流出泡；消费时带项退场并恰好新增一个用户块。
- **F-W23**：think chunk 不覆盖子代理块头的上一工具状态；无工具时显示当前思考词。

## 3. 活动与状态

- **F-W7**：turnState、Stop、digest 起跑/收尾、工具/耗时/turn/reasoning/token 等状态按当前协议显示。
- **F-A1–F-A5**：后台任务出生、终态、同名新代、清屏重建和控制面可靠；重载后不伪造未归档活动，归档靠记录。
- **F-W13**：逐项/批权限卡都携 promptId，Stop/Ctrl+I 可释放；迟到响应不匹配其他卡。
- **F-W16**：非零退出、killed、spawn failed 在卡色、展开或摘要中可见，活卡与恢复卡一致。

## 4. 设置与模型

- **F-W8**：打开设置时 proxy/websearch/index 等当前快照同拍到达。
- **F-W9**：推送回填活控件，不重建整卡、不丢半填输入。
- **F-W10**：未编辑控件不得把空值写回；显式清空才可删除对应配置。
- **F-W11**：shell 控件有实际保存与回填路径。
- **F-W12/N-W7**：host↔webview 顶级消息有生产与消费登记，不留无处置死 handler。
- **F-W14**：忙时可选模型/推理，显式选择不被回合尾 stamp 覆盖，下一回合生效。
- **F-W17**：provider、MCP、密钥/令牌及模型菜单删除均显式确认，取消零删除消息。
- **F-W18**：初始化不使用同步子进程冻结事件循环。
- **F-W19**：探针失败可在后续成功重探后自愈，失败原因不伪装成永久不可用。
- **F-W20**：首启提供本地 provider 与团队登录。
- **F-W21**：团队登录态在主界面可见，登/退有直达入口。
- **F-W24**：会话模式控件提供 tiny/normal/engineering 三选项，读取和保存同一槽内 mode；PLAN 只在 engineering 下受既有互斥约束。切换后下一轮提示词生效。
- **F-W15**：@file 展开只服务模型输入，恢复显示不展开文件正文。

## 5. 非功能

- **N-W1–N-W4**：webview 零运行时依赖/零构建；消息窗上限 150 块、卡体上限 64 × 1024 字符；流式走 rAF 脏集；历史恢复保真。
- **N-W5**：功能面按当前 VSC 测试清单机判，未覆盖处不得写成已验证。
- **N-W6**：端差须有宿主或行为依据。
- **N-W8**：设置打开、未编辑和推送回填的防数据丢失路径可机判。
