# VSC 文档归属 · 需求

> 通用归属规则 = `docs/core/design/DOC-SYSTEM.md`。

## 1. 当前文档家

VSC 专有产品需求位于 `docs/vsc/requirements/`，宿主实现设计位于 `docs/vsc/design/`。跨端共享机制位于 `docs/core/`，不复制到 VSC 文档。

## 2. 写作要求

新主题先查现有负责文档；有同主题文档就更新它，不另建平行档。需求回答用户可见能力，设计回答宿主接入和消息/状态机制。

引用使用当前有效路径、章节或符号，不依赖归档文档、批档或行号。文档变更同步文档地图和相关引用。

## 3. 验收

VSC 文档可被文档地图发现，核心机制没有端侧副本，当前规则不含迁移过程或一次性交付记录。
