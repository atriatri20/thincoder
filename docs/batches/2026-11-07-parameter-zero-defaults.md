### 为什么最危险的兜底是「参数默认值」（活样本 = 本日 `#2148`）

其它兜底（`catch` → 空集 ∥ `??` → 0）出错时**在错误点附近**，调用栈还在现场。

**参数默认值不同——它把错误搬到别处**：

```
target 缺省 → 拿锚当根 → 锚是工作区 → 没项目 → 猜根 → 域表读不到 → 空集
```

**链上每一层都"成功"了**。错误不在它发生的那一层冒出来，而在**三层之外的某个读数里**才被看见——那时没人能从报面倒回「是哪个参数被替了默认值」。

**⇒ 默认值兜底不是「多一层保护」，是替调用方做了一次没有依据的决定。**错误不是被修了，是被**改名**并**搬家**了。
