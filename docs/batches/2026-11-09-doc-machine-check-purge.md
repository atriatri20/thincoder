### 为什么这条必须走

提示词里有几处把「可机检」写成了验收的门槛，其中三处直接管文档：

- 需求五要素：`- **Acceptance** — each acceptance criterion machine-checkable;`
- 设计自检清单：`③ Acceptance criteria pointing back to requirements one by one (each machine-verifiable)?`
- 设计档要件：`- **Acceptance** — each criterion machine-checkable;`

文档的判据没法机检——它判的是意思，意思只有读的人能判。要求写在那儿，动手的人只剩两条路：编一个能跑的东西冒充判据，或者当没看见。我选了前者，于是编出了串探针。

撤掉这条要求，把「读得懂、读得出对错」写回去，才不会有人再往里塞串。
