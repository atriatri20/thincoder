|---|---|
| 收口前置门 | 本批单元档**必须已删**（零留存） |
| 文档机检门 | 档内引用**必须可解析**——删了就成 `档缺` |

**删了拒收口、不删也拒收口。**`#2114` 撞一次（7 处）、`#2117` 撞一次（2 处），**两次都是父侧越界去改别人的段**——因为两名作者互相锁（`edit` 判改后整档）。

**规则（甲形，用户已选）**：

> **引用方档在批档根下 ∧ 目标路径也在批档根下 ⇒ 该 token 不判**（不进命中，不报 `档缺`）。
> **规范档引批档照判**——那是 `D10` 方向纪律（「规范档引批档 ⇒ 删引用」）最后一道机检，**豁免它等于把这条规则拿掉**。

**为什么这个边界对**：用户给的理是「批档目录内容本来就不稳定」——**不稳定的是「批档内部互相指」这件事**。批档与它的产物**同寿命**（`D10`：「批档引批档不管，两者同寿命」）。规范档指过来是另一回事：**它本来就不该指**，所以不稳定不是借口，反而正是要判它的理由。

**实现点（设计席确认）**：`thincoder-core/doc-check/anchors.mjs` 的锚判入口已有引用方档（`refFile`）、解析结果含目标路径——**一个面判**：两边是否同在 `docRoot.batches` 根下。**不动解析序、不动豁免谓词、不动既有类。**

**边界**：

- **不放宽收口零留存**（单元档照删）。
- **不改措辞纪律**（不要求 `§2`/`§5` 用占位形——那条路与 `#2117` 的全路径要求直接冲突，已证走不通）。
- **不加白名单 / 不放宽存量**——这是**面判**，不是清单（清单 = 人工允许表，与本仓既定「基线保持为空」相抵）。
- **不动规范档 → 批档的判法**。

**验收**：

1. 批档 → 本批单元档（已删）⇒ **不判**（死锁消失）；
2. **规范档 → 已删批档 ⇒ 仍判 `档缺`**（方向纪律未失）；
3. 批档 → 批档（含前情指针、跨批引用）⇒ 不判；

### 机制设计（落点 = 设计 `docs/core/design/DOC-DISCIPLINE.md` §3.29 条目 AC）

- **面判句**：引用方档与目标路径**同在一个批档基底根下** ⇒ 该 token 不判（不进 `hits`、不读目标档、不计 `unreadable`，只计 `batchRefs`）。基底 = 声明面 ∪ 缺省回退（见下「基底与缺声明」一行）。
- **目标路径**：先拼后判，候选分形——① `<项目根>/<token>` 对任何 token 都拼；② `<引用方目录>/<token>` **只对不带目录段的裸名成立**。**不等解析结果**：目标已删时等 `resolved.abs`，死锁原样留着。② 只吃裸名是判据的一部分：带目录段的 token 拼上引用方目录恒落批档根下，越界照判就空了。
- **谓词与落点**：`isBatchFaceRef`（住 `thincoder-core/doc-check/anchors.mjs`，面判在解析之前跑）；两处消费 = 锚分支 ∥ 依据行分支，同一 token 不得一面判一面不判；计数 `batchRefs` 进 `checkAnchors` 返回值。
- **方向**：规范档 → 批档照判——引用方不在批档根下 ⇒ 面判不成立。
- **留痕**：`report` 面恒出一行 `批档面互引未判 N 处`（0 也出，行位 = 清点块之上、末行结论句之前）；`gate` 面零改。
- **基底与缺声明**：基底根与批档面同源单点（`thincoder-core/agent-tools/batch-paths.mjs` 的 `batchDocBases`——声明面 ∪ 缺省回退 `docs/batches`，恒非空）⇒ manifest 缺 `docRoot.batches` 键 ∥ 该键为 `null` ⇒ **回退默认基底、面判照常成立**；该根目录不在盘 ⇒ 引用照判。三种均不抛错（用例 = 设计 §5 用例表内条目 AC 那一组，以表为准）。本仓该键实读在盘 = `docs/batches`。

### 关键决策

- **目标按拼路径判，不按解析结果判**：死锁发生在目标已删之后；按解析结果判等于不治。
- **候选 ② 只吃裸名**：带目录段的 token 拼上引用方目录恒落批档根下 ⇒ 面判会变成「批档指到哪都不算」，越界照判（DD-211）与集成行 `7-6` 的改写同时落空。
- **同目录裸名一并豁免**：裸名只可能落在引用方目录里，② 是它唯一可能的落点；连带既有集成用例 `7-6` 的夹具 token 改为仓根全路径（该行证的东西不变）。
- **`gate` 面不加留痕行**：gate 首行是机器判据，夹读数会把「判域 = 命中」读浑；人读的是报告态与批档回执。
- **不动行号面与段面**：两条判据各管各的事。
- **列表不写计数别名**：判据总表与族首行不写「N 条 / N 项」——列表本身是单源，别名存在一天就要维护一天，旧档不是留下的理由。
