### 判据（本批的核心设计，A2）

**纪律句**：凡文档把行号写成规定的**证据形**或**定位形**（即给出「档名 + 冒号 + 数字」这个可照抄的形状），那句话本身就在教人写行号 ⇒ 同批换形；只清实例不清规则句 = 边清边长（实例是存量，规则句是产源）。

**换形 = 该档 D4 细则「换形怎么落」表的五种落法**（闭枚举，单源 = 该档，本批不另立第六种）：按「这一处指的到底是什么」选一行——规则 / 判据 / 约束 ⇒ 档名 + 节名 + 逐字引文；代码件 ⇒ 符号名；量 ⇒ 量法 + 量取日期；数据档 / 配置档的键 ⇒ 键名路径 + 所在节；同档自指 ⇒ 节名 + 逐字引文（档名可省）。

**判法 = 人判 + 可复扫的候选形**（机器判不了：它数得出字面，数不出散文化的说法——`docs/core/design/PROMPT-SYSTEM.md` 的 K5 行已记这个边界）。候选形两条须同时成立：

- ① 一行内出现**元变量坐标**——档名 token 紧跟冒号，冒号后不是数字而是一个占位（`file:line` ∥ `档:行` ∥ `档名:NN` ∥ `<源档>:<行>`）；实例用真数字，规定用元变量，这就是产源与存量在可判面上的分界。
- ② 同行含规定动词：证据 ∥ 落点 ∥ 必须 ∥ 一律 ∥ 格式 ∥ 登记 ∥ 写法 ∥ 指针。

命中者一律进**候选清单**，逐处由人判（判法见下「不判面」）；候选取的是形状，判的是语义——两者不混。

**四条不判面**（与 D10「示形不判」同源：教写法的样例判不出，也不许判成违规）：

① **反例 ∥ 被讨论对象**：元变量作为被计数的对象出现（「`X.md:NN` 也作 token 计」这类说的是抽取式本身），或作为反例出现；② **引文内坐标**：别人原话里的号是引文字面（本档 D4 已立，逐字不动）；③ **清账单 ∥ 报告的逐处行形**：它的对象就是那枚坐标、寿命随该轮（清单读完即删，号随之消失），换形无处可落；④ **围栏块内**（与 §3.23 围栏口径同）。

**为什么 ③ 单列**：报告要指的位置就是「那一枚坐标」——去掉号，清单读不出该改哪一处；这不是「拿位置当长期依据」，与永久面的形是两件事。把 ③ 并进禁列，等于让清账工具自己违规。
