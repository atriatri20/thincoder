### 量法（可复跑 · 本批唯一一把尺）

同尺 = `node` 行扫描。跑法：仓根下 `node` 执行下方脚本（域 = 本节五档，写法见围栏）。

```js
const fs = require('node:fs');
const files = ['CORE-UNIFICATION','ARCHITECTURE','WORKSPACE','STRUCTURE-DEBT','TWO-REPO-MERGE'];
const UNITS = /(\d[\d,]*(?:\.\d+)?)\s*(档|处|条|行|份|次|个|位|名|项|款|轮|字符|字节|%|倍|家|篇|节|张|块|人)/g;
const FENCE = /^(\s*)(`{3,}|~{3,})/;
const BARE = ln => ln.replace(/(`+)[^`]*\1/g, '');
const SKIP = /[≤≥<>]|软线|硬限|阈值|字符上限|第\s*\d+\s*条/;
for (const f of files) {
  const p = `docs/core/design/${f}.md`;
  const lines = fs.readFileSync(p, 'utf8').split(/\r?\n/);
  let open = null; const out = [];
  lines.forEach((ln, i) => {
    const fm = FENCE.exec(ln);
    if (fm) { const ch = fm[2][0], len = fm[2].length;
      if (open === null) open = { ch, len }; else if (ch === open.ch && len >= open.len) open = null; return; }
    if (open !== null) return;
    const bare = BARE(ln);
    if (SKIP.test(ln)) return;
    const m = [...bare.matchAll(UNITS)];
    if (m.length) out.push(`${i + 1}\t${m.map(x => x[0]).join(' | ')}\t${ln.trim().slice(0, 150)}`);
  });
  console.log(`===== ${f}  candidates=${out.length}`);
  out.forEach(x => console.log(x));
}
```

候选 = 数字 token 紧贴计数单位（围栏块跳过、行内码段剥离、阈值行与「第 N 条」规则编号行排除）。候选不是判据值：每处必须回所在节判 U-5（撤）∥ U-6（留），零正则命中也不作为「已判完」的证明。
