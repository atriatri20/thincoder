### 2.3 机制设计（逐处四步）

1. **读所在节**：读该数字所在的整节，不看单行——节的主题决定这个数答的是「规则是什么」还是「那次跑出了多少」。
2. **判类**：按 §3.30.1 三行落下。判「留」的四类：阈值 / 夹具输入与预期 / 行为契约中的数量 / 有本节目表撑着的合计与结构数（U-6）。判「撤」的：当前库存、一次扫描的覆盖量、改前改后绝对行数与净增量、样本量、一次清账结果及其派生比例。
3. **撤或留**：撤 = 把读数片段删掉，同句的规则句逐字保留；留 = 一字不动。
4. **同轮收正**：撤数的那一段里，剩下「已落 / 越线 / 在盘 / 零改 / 全部」类断言按盘重核（U-5 补条）；接不住就改写，改不动就报回上抛项、不撤。

**接不住的处置**：按用户口径「接不住的别撤，报我」——进 §2.8 上抛项，不自行造替代句。

### 2.4 量法（本批判类与读数的取法）

- **候选面（判类用，不是判据值）**：逐节读六档全文，把「形如数字且可能答『那次跑了多少』」的行记为候选；候选清单逐条登记在 §2.6（档名 + 该处现文逐字引文 + 判类 + 处置）。**判据值 = 逐条的判类结论，不是候选数**。
- **复跑面（残留核查）**：`doc_check`（gate 模式）判六档，首行须 `DOC-CHECK GATE: PASS`。
- **撤数后的重核面**：改动段落按 `git diff` 逐段读回，同段的断言句按盘核。
- 数值一律不进本档文字之外的规范面：本档的逐档读数（候选 / 残留）住本节 §2.6，且只作本批执行记录。
