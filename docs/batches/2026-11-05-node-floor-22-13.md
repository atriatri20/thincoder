**② 库外一手源**

- **Node 官方 v22 文档（`nodejs.org/docs/latest-v22.x/api/sqlite.html`，v22.23.4）**：`node:sqlite` 的用法即 `new DatabaseSync(':memory:')`，**正文无 `--experimental-sqlite` 前置**；Stability 标 `1.1 - Active development`。
- **鸿蒙侧**（同夜另一支调研）：`DevNode-OH` 提供 node v24.13.0；openEuler 子系统 `sudo dnf install nodejs` 可用但版本常低于 24。

**③ 扫描结论（有限证据，标 `unverified` 面）**

父侧扫了 `Error.isError` ∥ `Float16Array` ∥ `URLPattern` ∥ `process.execve` ∥ `import.meta.dirname` 五个典型 Node 24 专属 API，**CLI 面零命中**。

**⇒ 但「扫五个典型」不等于「扫全」**——「CLI 不用 24 专属 API」这一条**未经全量证明**，本批必须以实跑兜底。

### 父侧判断

**「≥24」不是代码逼出来的**：核已在 22.13 上跑（VSC 扩展宿主就是 22.13，且核内明令禁用 24 专属 API），CLI 只是核的壳，**门槛却比核高一档，且抬高的理由没落到一个具体 API 上**。

**⇒ 落到 `>=22.13.0`，与核同线**（不是笼统「22」：22.13 才是 `node:sqlite` 免 flag 的起点；22.5–22.12 仍需 flag，那才真跑不了）。

- **已定决定**：CLI 的 Node 下限由 `>=24` 降到 `>=22.13.0`，与核同线；判据 = 主次版本比较（`22.13` 过、`22.12` 拒），且 **Node 22.13 上实跑全绿**。· 用户原话：「cli我们也没必要要求nodejs24以上吧？22应该也可以。」+「开」 · 时间：2026-11-05 21:22

## 机制设计

**判据**：版本串取 `major.minor`，通过条件 = `major > 22 || (major === 22 && minor >= 13)`。实装单源 = `thincoder-cli/bin/node-version-gate.cjs` 的 `nodeVersionError`。

| 类 | 输入 `version` | 期望输出 |
|---|---|---|
| 常规 | `24.19.0` ∥ `30.0.0` | `null`（放行） |
| 边界 | `22.13.0`（恰在下限） | `null` |
| 边界 | `22.13.1` ∥ `22.14.0` ∥ `v22.13.0` ∥ `22.13.0-nightly20250101` | `null` |
| 边界 | `23.0.0`（跳主版本） | `null` |
| 边界 | `22.12.9`（差一档） | 拒：`thincoder requires Node.js >= 22.13.0 (current: 22.12.9)` |
| 错误 | `22.9.0` ∥ `21.7.0` ∥ `20.19.0` | 拒（同形文案） |
| 错误 | `"22"` ∥ `""` ∥ `"abc"` | 拒（不可解析 ⇒ fail-closed） |

**出口**：`enforceNodeMajor()` 行为不变——`null` 静默返回；非 `null` ⇒ `console.error` 一行 + `process.exit(1)`。

**为什么不用 semver 包**：零第三方依赖是硬约束（`docs/core/design/ARCHITECTURE.md` §1.1 约束 4）。正则 + 两个整数比较够用，取值域由上面这张表圈死。

**`node:sqlite` 一侧的实证来源**：`docs/core/design/CORE-UNIFICATION.md` 的 A8 行——「`node:sqlite` Added in v22.5.0；v22.13.0 / v23.4.0 起不再需要 `--experimental-sqlite`」。核早已按 22.13 设计，本批只把 CLI 抬到同一线。

## 关键决策

1. **下限取 `22.13.0` 而不是 `22`**：22.5–22.12 的 `node:sqlite` 需 `--experimental-sqlite`，核装载即失败——笼统「22」会放行一批必然崩的宿主。依据 = `docs/core/design/CORE-UNIFICATION.md` 的 A8 行。
2. **判据比两个整数，不用「主版本 × 100 + 次版本」**：后者是魔数，读的人还得反推；直接比 `major` ∥ `minor`，判据句与代码一眼对得上。
3. **错误文案与 `engines.node` 同拼写**（`>=22.13.0`）：现状是两处各写一遍（`>= 24` ∥ `>=24`），本批统一，并加一条单测断言钉住。
4. **保留 `nodeVersionError` ∥ `enforceNodeMajor` 两个名字**：`docs/cli/design/CLI-ENTRY.md` §1 与 `thincoder-cli/bin/disk-root-gate.mjs` 头注都以它们为先例引用；改名 = 多处连带改，收益为零。
5. **22.13 实跑只跑 CLI 面 + 核面冒烟**：本批要证的是「CLI 及其装载的核在 22.13 上可跑」，不是「全仓在 22.13 上可跑」。
