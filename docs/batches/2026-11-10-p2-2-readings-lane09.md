### 判类（本批唯一判据）

判类读 `docs/core/design/DOC-DISCIPLINE.md` §3.30.1 三行与 §3.22 的 U-5 / U-6。一句话：**这一行答的是「规则是什么」，还是「那次跑出了多少」** —— 后者撤，前者留。

| 类型 | 撤哪个面 | 留什么 |
|---|---|---|
| 档数 | 当前库存、一次扫描覆盖量、命中档数、无本节目表支撑的合计 | 目录全集、文件闭集、扫描域与排除面（用集合差取数） |
| 处数 / 条数 | 当前命中处数、样本量、一次清账结果及其派生的比例与倍数 | 条目定义、正则、判定谓词、排除面 |
| 行数 | 当前行数、改前改后绝对行数、净增量 | `doc_check` 的 `lines` 量法与尺寸阈值 |

**阈值必须留（本批用户口径）**：输出上限的字节数 / 行数、schema 字段上限、段落阈值一类，是判据而不是读数 —— 撤了它判据就没了。撤的是「当前实读 = N 档 / N 处」这种**当下库存**句。

**免责标签无效**：数值旁写「实读」「基线」「只作记录，不作判据」不改变判类（U-5）。

**U-5 补条**：删掉一句里的读数之后，同句剩下的断言（「已落」「越线」「在盘」「零改」）必须按盘逐条重核，不成立即同轮改写。

### 每处的处置形（五步，一步不省）

1. **定位**：按候选表进节，或按节读全文（候选表漏的那处，靠逐节读兜住）。
2. **判类**：读所在节，答 U-5 那一问；表支撑的合计按 U-6 判留。
3. **处置**：撤 —— 删读数片段，同句规则句逐字保留；留 —— 阈值 / 量法 / 结构数 / 夹具输入预期 / 行为契约数量。
4. **同句重核**：删数后同句断言按盘核（U-5 补条）；不成立即同轮改写。
5. **登记**：每处按「节名 + 现文逐字引文」登记，读数只住批档 §5，不进设计档。

**接不住的别撤**：判不出是读数还是判据的，原样留着并列进本段上抛项 —— 撤错的代价是一个判据消失，比留一处读数贵得多。

### 关键决策

- **按判类删，不按数字形状批量删**：正则只定位，判类在节里做（§3.30.1；同档一个「3 条」可能是闭集结构数，另一个是读数）。
- **上限留、库存撤**：输出上限是阈值判据；「当前实读 N 档」是读数。二者形状相同、判类相反，靠读节分，不靠规则外挂。
- **接不住就上抛，不硬撤**：撤错不可逆（判据消失），留一处读数可下轮再判。
- **不新增机检器**：不为「零读数」造全仓数字正则门 —— 那会误伤阈值与夹具（§3.30.4）。
- **读数只住批档**：每处的候选数与处置登记落 §5，设计档零读数残留（D12）。
