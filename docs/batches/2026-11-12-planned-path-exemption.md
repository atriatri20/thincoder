- **判据**：一条 token 走完全部解析腿仍解不到时，若目标路径落在**在途批档 §2 机读清单**的并集里 ⇒ 不判 `档缺`，解析结果记 `how:"planned"`；声明集之外照判。

- **声明面复用既有**：在途判据 = `isBatchRecord` ∥ `readBatchStatusLine`（`thincoder-core/agent-tools/batch-segment-vocab.mjs`，零 import 词表叶档）；§2 机读块的块头正则与两表解析本批从 `batch-tier-gate.mjs` **上移**到同一叶档，档位臂改 import（只搬不改）。
- **落点**：`档缺` 的三个产出点（路径线 ∥ 依据行 ∥ 花括号组展开名）收成一个共用入点，计划件判在它里面。

**代价（照实，单源 = 设计档 §2.12.2）**：判据从「这个文件存在」变成「这个文件在被计划」，而计划只在批档活着时成立。
