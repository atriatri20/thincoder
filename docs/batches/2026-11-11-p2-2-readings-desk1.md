### 量法（本批唯一尺 · 可复跑）

同尺 = `node` 行扫描；域 = 单档全文；围栏块整块跳过（同字符且关闭长度 ≥ 开启长度才算闭合）；整行含阈值的行排除；行内「第 N 条」规则编号剥除；不剥行内 code span（读数常写在反引号里）。正则逐字如下（cwd = 仓根）：

```js
const FENCE = /^(\s*)(`{3,}|~{3,})/;
const CAND  = /\d[\d,，]*\s*(档|行|处|条|节|份|例|项|次|名|串|字|段|个)`?/g;
const THRESH = /(≤|≥|>|<|软线|硬限|阈值|上限|字符数)/;
const RULENO = /第\s*\d+\s*条/;
```

候选数只作「这一档有多少数字要过判」的尺寸描述，不作判据值；判据 = 逐处读所在节后撤或留。删除数值后同句的关系句、验收句、计数句同轮收正。

- **正常 · 条数**：命中数、样本量、清账结果撤净；谓词、域、排除面与归零判据在位。
- **正常 · 行数**：六档所有绝对行数撤净（含档头三处）；尺寸阈值、越线结论与 `doc_check` 的 `lines` 量法在位。
- **边界 · 表格构成**：闭集结构数与枚举合计按 U-6 保留，无一处删数破算式。
- **边界 · 行为契约**：夹具输入与预期、`200 条`页量、`150` 块窗、队列 `8` 条容量原样。
- **错误 · 免责留数**：本批未使用任何「实读 ∥ 历史 ∥ 只作记录」标签保数——撤就是撤。
- **错误 · 删数留假断言**：三类越线结论按盘重核后保留；不成立的（「已建成」）同轮删除。
- **读者验收**：打开六档任一 `文件账`，列头读 `行数面` 而列内无绝对数；打开任一 `机检 = 单元测试档` 句，读到的是用例构成而不是行数与红绿比。

### 关键决策

- **档数 ∥ 条数 ∥ 行数三类之外一律不撤**：版本号、依赖版本、键数、`6px` 这类形态值不属三类，本批零笔（「接不住的别撤」）。
- **列头比单元格更该先改**：`预估行数` 是一个「目标绝对行数」的位置名，列内数字撤了而列头留着，下一位作者照列头补回绝对值。
- **不新建机检器**：§3.30.4 明写不为「零绝对读数」造全仓数字正则门；判据 = 逐节读者判读 + `doc_check` gate。
- **量法两把尺分开报**：正则候选与逐节读点出的裸数单元分列，因为正则抓不到裸数（父侧口径「别信正则」）；两列不做加减。
