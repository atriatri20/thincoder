# Render Core · 需求

> 同题设计 = `docs/render-core/design/RENDER-CORE.md`。
> 本档是宿主无关渲染核需求的唯一 owner；VSC、Desktop 与 Server 只登记各自接入和宿主职责。

## 1. 模块目标与边界

渲染核向浏览器渲染面提供零第三方运行依赖的原生 ESM 纯函数与 DOM 构件。核可以使用 DOM、剪贴板和 `requestAnimationFrame`，不得获取 VSC 句柄、调用桌面 IPC、读取宿主会话存储或决定宿主消息分发。

包通过子路径导出公开模块。宿主负责静态资源供给、样式变量、消息传输、会话记录、历史分页、块挂载位置和业务副作用；核不建立另一套 agent、会话或配置数据层。

## 2. 文本、流式与帧

- **RC-T1**：`md` 与 `mdInline` 必须先转义不可信文本，再渲染当前支持的 Markdown 构造；链接与图片 URL 只接受 `http`、`https`、`mailto`、锚点和相对路径，其他带 scheme 的 URL 降为 `#`。
- **RC-T2**：流式正文采用冻结前缀与热区增量渲染。只有可证明已闭合的段落或块才可冻结；未闭合构造保留在热区。非前缀扩展、热区失连或切点倒退必须全量重绘；渲染异常必须显示原始文本并清空增量缓存。
- **RC-T3**：多面帧合并与单目标流式渲染的最小帧间隔均为 50ms。`apply` 异常不得吞掉，异常后新的脏标记仍可起帧；`flush()` 必须同步画出当前脏内容。
- **RC-T4**：工具输出追加采用原位置写，卡体上限为 64 × 1024 字符；超限附当前截断标记并停止后续追加。全文保留责任属于宿主会话记录。

## 3. 滚动与窗口

- **RC-S1**：近底距离为 `scrollHeight - scrollTop - clientHeight`，阈值为 `max(24, clientHeight × 0.5)`，仅在距离严格小于阈值时判近底。非法几何读数按 0 处理；阈值始终为有限值且不小于 24。
- **RC-S2**：`applyPin` 只在旗标不为 `false` 时写回底部；不得在用户让位期间抢夺阅读位置。近底无条件恢复 pin；手势门控模式的让位窗为 600ms。
- **RC-S3**：可选的上滚解钉由 `wheel.deltaY < 0` 触发，不看滚动距离。600ms 内再次上滚续期，窗内不改旗标，到期后按近底状态恢复或保持解钉。
- **RC-S4**：未读计数随宿主元素保存，支持递增、清零和读取；点击回底、近底恢复和元素换代均可清账。回底按钮、消息窗裁剪和历史 prepend 的视口补偿由宿主承接。
- **RC-S5**：块内容区跟滚在追加后、挂载后与帧尾应用；折叠或已离连块不得产生滚动副作用。

## 4. Composer 与附件

- **RC-C1**：Enter 发送，IME 组合期与 `@` 下拉优先；多行历史导航遵守单行、多行边界和草稿恢复规则。无工作区时拒发并保留文本。
- **RC-C2**：忙时普通消息进入容量 8 的队列；满队拒绝并保留文本。斜杠命令在入队前本地路由，未知名称、参数拒绝和命令门拒均不得进入消息通道。
- **RC-C3**：图片只接受 png、jpeg、jpg、gif、webp。文本附件按 `text/*` 或公开扩展名表受理，单档不超过 256000B，每回合不超过 4 档且合计不超过 512000B；前 8000B 含 NUL 时按二进制拒绝，所有拒绝均有可见反馈。
- **RC-C4**：文本附件发送时内联为文件名头与 fenced 段，围栏长度必须大于正文最长反引号串且至少为 3。模型与推理控件在忙时仍可选择；自动推送不得覆盖忙时显式选择。
- **RC-C5**：工作模式控件使用同一 tiny/normal/engineering 字符串，提供固定三选项并统一发出 setMode；不得另存可写 ENG 布尔。只有 engineering 与 PLAN 保持互斥。

## 5. 活动块与恢复

- **RC-A1**：relay 前缀支持任意深度 `role#数字/`。事件只产出 `started`、`queued`、`turn`、`done`、`settled`、`cancelled` 六类状态；`stopped` 输入映射为 `cancelled`，其他事件不得泄漏为可见正文。
- **RC-A2**：`queued` 与 `started` 可出生或接管新代；迟到内容不得复活冻结块或墓碑块。queued 取消移除等待块，普通终态冻结并归档，`settled` 冻结后驻留待消化，后续 `done` 在轮边界归档。
- **RC-A3**：`turn` 只更新存活块；审批只更新既有存活块；终态缺失时仅对合法角色和 id 补桩。`answered` 无块不补桩，queued 取消不补桩。
- **RC-A4**：工具调用行始终新行；同一工具、同一嵌套身份的 `toolOutput` 原文续写合并，不插入分隔符。think 不覆盖既有工具状态；只有状态为空且存在嵌套身份时才写入 `<sub>/<think 词>`。
- **RC-A5**：核只维护内存模型与有序 DOM 效果，不持有宿主会话存储。未归档活动不跨 reload 伪造；已归档块和 digest 由宿主记录重建。

## 6. 验收边界

需求复核至少覆盖以下负例：距离恰等于阈值不判近底；旗标为 `false` 不写 `scrollTop`；`apply` 抛错后新标记仍能排帧；满队、超限附件和 NUL 附件均拒绝且保留既有输入；冻结块不接收迟到 chunk；非法终态身份不补桩。

公共导出的逐项参数、返回值、常量和状态效果以同题设计为准。宿主分页大小、窗口裁剪、记录格式和出站协议由各自端文档定义，不在本档复制。
