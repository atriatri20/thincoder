# Desktop 会话 · 需求

> 设计 = `docs/desktop/design/SESSIONS.md`。

## 1. 项目与会话

- **D1**：打开文件夹或最近目录建立 cwd 上下文；全退后重启自动打开本端上次打开的项目并接续会话。无有效记录保持冷态。
- **D2**：新建、列表、切换、删除、重命名、接续使用同一 core sessions 目录，与 CLI/VSC 可接续。
- **D18**：会话下拉显示标题、provider、真实消息计数、updated、运行/审批位标与改名/删除操作。
- **D23**：消息计数不可得时不显示或显示不可得标识，不能降级成 0；计数包含人读线记录。
- **D26**：回合尾在整档保存前生成标题，失败非致命并可在后续回合重试；未命名老会话仅自然补，手动改名可用。

## 2. 删除与异常

末项删除由 UI 与主进程共同拒绝；删除活动会话后按当前邻位/空态接管，失败不改变活动会话。

账本异常在下拉中可见，损坏现场与拒写原因不得伪装成正常空账。
