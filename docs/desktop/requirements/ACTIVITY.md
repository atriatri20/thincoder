## 功能点

| # | 功能点 | 判据（可机检） |
|---|---|---|
| D4 | 活动与后台 | 子代理活动块（粒度 = 角色 · 模型 · 用时 · 回合 + 状态词；**内容回显 = 核件 tail-3 / 展开** · **内容区跟滚**（流式最新保持可见 · 用户上滚不抢 · 回近底复跟 · **停跟态可见出路**：↓ 新内容 ∕ 回到最新〔可滚 ∧ 停跟 ⇒ 钮在场〕））、advisor / consult、挂起态与 digest（**digest 显示 = 自然形（行出即留）**——现行文 ∥ 判据 = **D28**）+ **空闲唤醒 + 完成提示面**、**排队消息 = 输入区上方待发送带**（消费前流内零块）；右列「队列」族不承载用户排队消息 |
| D20 | 右列 = 子 agent 面板 | 右列显示**子 agent 实例**（sync / async / consult / escalate / advisor-async 五类射程）；数据源 = relay 事件（宿主已解析：`thincoder-desktop/src/main/agent-bridge.mjs:15-27`）+ 心跳补发；块态机（出生 / 终态折叠 / **归档 = 入流**〔终态 ⇒ 流内留场块 + 表项墓碑〕）；**块面 = 核件同款**（内容 tail-3 + 展开 + `ev:subchunk` 内容增量）+ **流式期近底保持**（区帧尾跟滚）；**停跟态可见出路**（块内容区 ↓ 新内容 ∕ 回到最新）；**右列加宽一倍**（`--pool-w: 36rem`）；停止出口在位；**零工具调用行残留**；**已消化驻留自愈**：块呈「已完成 · 等待消化」而报告已入模型上下文（核侧无驻留）⇒ 宿主自审补发归档（分钟级——不等手动冻结）；丢帧类滞留不得须用户介入 |
| D28 | 消化面留档 + 显示 = 自然形（行出即留） | 消化生命周期两面**刷新 ∥ 重载 ∥ 切走切回均在**——① **显示 = 自然形**（行 = 流内事件——起跑行 ∥ 计数行 ∥ cap 行 ∥ 终态行：**不改 ∥ 不删 ∥ 不退场**；**终态 = 追加一条新行**——不动原 digesting 行；跨端对齐 = 设计档 §10 **DA ①** 重开登记（处置待裁））；② **记录面 = 三端档里全量照留**（读盘按需、不驻内存；**已撤销 ∥ 已删会话除外**——回合代次门）；③ 被消化的子 agent 归档块 = 留档块（页读域第六型）——**固化块落位 = 消费轮族之后**（随到达入流）；④ 记录**入人读线 ∥ 不入机器线**（不喂模型）；**未结轮照现**（全量重放——可证面 = 轮间 ∥ 末页（扫描结束仍 `open`）；位次门 = `at` 不可得 ⇒ 该轮零产；**归属 = 活流侧优先**——运行期未结轮在场 ⇒ 折叠未结末轮不并入 ∥ 运行期未结轮跨首屏存续）；验收 = 机检八用例 + 真机一条 + 收正面（自然形（行出即留）∥ 落位 ∥ 无闪现——设计定形） |
| D30 | 右栏宽度拖动 | 右栏（右侧列 = 子 agent 面板 / Activity）**宽度可拖动**——中列 ∕ 右列交界给拖动柄；① 拖动**即时生效**；② 宽度**持久化**（重启恢复）；③ 基线 = 现盘恒值（`--pool-w: 36rem`）——**无自动收窄机制**；故**单一权威 = 用户值**（未拖过 ⇒ 现盘默认宽度）；范围上下限 = 设计定形；实现形待设计 |
| D35 | 右栏池超高可滚动 | 右列子 agent 面板**实例极多时内容超高须可滚动**；滚动容器已在设计内——`.pool-body` = `overflow-y: auto`（+ `pool.css`「封顶自滚」条注 ∥ `chrome.css:51`）；当前实测 21 子块未溢出（`scrollHeight == clientHeight`）⇒ 用户所遇「不可滚」**触因待定**（高度约束链 ∥ 让位 ∥ 跟滚逻辑 ∥ 极多实例布局面——设计轮先按现场复现定位）；实现形 = 批（设计已落） |
