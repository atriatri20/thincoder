# Desktop 活动池与消化 · 需求

> 设计 = `docs/desktop/design/ACTIVITY.md`。

## 1. 活动

- **D4/D20**：右列显示 sync/async/consult/escalate/advisor 子代理，含角色、模型、状态、用时、turn 与 tail/展开内容；不重复普通工具卡。
- 内容区跟随最新输出，用户上滚不抢，回近底恢复，停跟时有回底出口；停止入口可用。
- 终态折叠并归档入流；已消化但滞留的块按当前补发/自愈路径归档。

## 2. 消化记录

- **D28**：digest 起跑、计数、cap、终态与残余按事件自然追加，不改写或删除既有行。
- 记录进入人读线而不进入模型机器线；重载按记录位次重建，未结轮按当前规则显示。
- subagent 快照作为第六类页读块，记录计入分页条目与隐藏数。

## 3. 布局与提示

- **D30**：右栏宽度可拖，用户值持久化并受当前上下限。
- **D35**：实例很多时池体可滚动，钉底不能阻止用户上滚。
- 完成提示只在当前失焦与用户回合完成条件触发，不为后台 digest 制造噪音。
