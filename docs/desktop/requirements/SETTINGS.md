# Desktop 设置与首启 · 需求

> 设计 = `docs/desktop/design/SETTINGS.md`。

## 1. 设置面

- **D7**：provider 增删、key、三协议、agent 参数与中英文设置可用；删除不可复得条目需确认。
- **D8**：索引、memory/code_search/doc_search 状态和构建入口复用 core。
- **D9**：MCP 增删改、探活、重连和工具清单可用；保存失败与探活失败可见。
- **D37**：设置行、渠道两行卡、表单、拨杆和弹窗与 VSC 当前视觉语言一致，功能不减少。

## 2. 首启

- **D11**：本地 provider 与团队登录两路都可完成；失败就地显示并可换路。
- 保存按钮明确；保存并继续不会静默丢 key；校验结果就地可见；未完成配置点完成时被拦住并给明确选择。
- **D16**：无项目/无会话有真实引导按钮；可见变化的验收包含真 Electron 使用面。
- **D39**：设置菜单可打开对应组的应用内模态，复用同一读写链，现有设置页仍可用。
