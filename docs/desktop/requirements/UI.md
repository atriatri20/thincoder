# Desktop 界面与视觉基线 · 需求

> 设计 = `docs/desktop/design/UI.md`。

## 1. 信息呈现

- **D10**：台账读数经当前事件链显示；批次/项目状态只有在真实消费链存在时呈现，不造假入口。
- **D15**：上下文读数按会话 key 更新，未到达或无效时无节点。
- **D17/D22**：状态行覆盖当前 CLI 同义信息，包括 banner、当前工具、耗时、任务、turn、usage、上下文、台账、timer、标题、输入/排队、attention 和团队态；恢复时按槽播种。
- **D21**：Markdown、推理、工具与会话面视觉使用 render-core 当前值，保持桌面外壳布局。
- **D24**：外壳静息减少无意义描边，交互态与审批/提问等语义强调仍清楚。
- **D29**：桌面自有排版使用统一字体、字号、行高和字距；Markdown 语义修饰保留但不另建独立排版体系。
- **D33**：主题支持 system/light/dark，重启记住用户选择。

## 2. 交互

输入、审批、提问、会话控制、菜单与设置可键盘操作；状态词来自当前闭集，空态有真实下一步入口，错误与失败可见。

长会话的窗口、回填、跟滚、摘要和离屏处理不得改变用户阅读位置或会话全史。
