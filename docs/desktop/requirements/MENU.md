# Desktop 菜单 · 需求

> 设计 = `docs/desktop/design/MENU.md`。

## 1. 主菜单

- **D36**：文件、编辑、视图、设置、帮助五组使用原生双语菜单。
- 文件含新建会话、打开目录和最近目录；编辑含标准编辑与查找；视图含重载、开发工具、缩放、全屏和主题；设置含设置页、配置组和维护；帮助含更新、命令/快捷键和关于。
- 主题当前项带勾，关于显示真实版本，窗口操作由系统标题栏承担。

## 2. 通道

菜单命令经 ev:menu 到现有单一实现；theme:state 回报当前主题以刷新勾选。动作非法时显式失败，不新增平行 UI。

## 3. 设置入口

- **D38**：设置组含“设置…”和维护子组；配置组弹窗与完整设置页都可到达，模型选择仍归输入区。
