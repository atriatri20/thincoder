# Desktop 打包与发行 · 需求

> 设计 = `docs/desktop/design/PACKAGING.md`。本档描述发布契约，不是发布完成记录。

## 1. 产物

- **D12**：Windows/macOS/Linux 均有可安装、可启动的目标形态；Windows 使用当前 NSIS x64 链，Linux 使用 AppImage 与 deb，macOS 目标随其发布面验证。
- **D32**：官网提供桌面下载；Windows 商店与 Snap 按发布计划接入，MAS 不做。签名在证书可用时实签，缺席明示。

## 2. 更新

- **D40**：打包应用启动后按当前延时检查，后台下载，完成提示重启安装或退出时安装；手动检查可用，失败不影响使用。
- **D41**：官网提供桌面介绍、下载、系统要求、更新说明和 feed；包名、package.json、feed 与站点版本一致。
- **D42**：Linux AppImage 使用自动更新，deb 由包管理器手动升级；构建产物经过结构与启动验证。

## 3. 发布边界

发布、上传和商店账号操作由用户授权。构建机、CI、证书和真机冒烟的结果必须按实际运行记录，不能在需求档预写为通过。
