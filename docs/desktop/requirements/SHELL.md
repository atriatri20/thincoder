# Desktop 宿主壳 · 需求

> 设计 = `docs/desktop/design/SHELL.md`。

## 1. 编辑菜单

- **D27**：输入框右键提供剪切、复制、粘贴、全选；非编辑选区提供复制、全选；空选不弹空菜单。行为与剪贴板真往返。

## 2. 窗口

- **D31**：每次重启主窗口都以最大化显示，包括上次手动缩小后退出；运行中不强制用户窗口大小。

## 3. 隔离

主进程独占 Node/core，preload 仅暴露白名单，renderer 无 Node。启动必须验证 Electron 内置 Node 与 node:sqlite 可用，失败明确退出。

配置写只经 core，协议资源不泄露目录外文件，第二实例唤醒既有窗口。
