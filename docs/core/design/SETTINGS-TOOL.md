# settings 工具（SETTINGS-TOOL）· 设计

> 需求 = `docs/core/requirements/SETTINGS-TOOL.md`。
> 最近先例：`docs/core/design/CONFIG.md` 的原子写与派生视图。对齐 = 同一配置、同一写链；偏离 = 本档负责工具 schema、寻址、遮蔽与热应用。

## 1. 定位

`settings` 是 `/config` 等用户界面的 agent 工具对应面。工具不替代用户界面，也不允许绕过配置写链。

## 2. 机制契约

### 2.1 注册与动作

实现 = `thincoder-core/agent-tools/settings.mjs` 的 `settingsTool`。

- action = list / get / set。
- list/get 为只读，set 为副作用动作。
- 工具描述 = `thincoder-core/tool-docs/settings.md`。
- 主 agent 和子代理的实际装配按工具面规则执行。

### 2.2 键寻址

点路径逐段下钻，数组数字段作为下标。list 展平当前 live config 并排序；get 对缺失段返回 reached、missing、depth 等诊断。

set 可以创建中间对象，但键的持久性仍受 loadConfig 保留域约束。

### 2.3 写盘与热应用

set 的顺序保证失败不产生假成功：

1. 解析并校验值。
2. 通过 writeConfigAtomic 新鲜读、点改、冲突检测和原子写。
3. 写成功后更新 agent.config 的目标键。
4. 同步受影响的派生视图。
5. 返回持久化与实际热应用结果。

派生视图同步遵循：

- 子键 set 只同步该键，不用默认值覆盖会话级值。
- null 删除同时清理嵌套与派生视图，再按真实默认规则读取。
- 整段对象赋值使用同一 promote 合并函数。
- 运行视图未包含的端侧配置以写盘和后续真实读取为准，不虚称所有消费者已即时更新。

### 2.4 敏感判定与输出

`isSensitiveKey(path)` 使用段级词表和开口键族：

- 识别 key、token、secret、password、authorization、cookie、credential 等敏感段及复合名。
- headers 与 env 下的值整族遮蔽。
- 键名保留，值显示 `••••（masked）`。
- list、get、set 回显和错误值位都使用同一谓词。
- 敏感父对象整体遮蔽，不展开其中明文。

### 2.5 值解析

`parseValue` 先 JSON.parse：

- 对象、数组、数字、布尔、null 使用解析值。
- JSON 字符串去掉语法引号。
- parse 失败时使用原始字面字符串。

### 2.6 类型与形状

- 非 null 默认叶子派生 typeof 约束。
- null 默认叶子使用显式形状表。
- 同族和跨面键使用相应形状表。
- 已知键接受 null 或真实可消费形态时，按消费规则处理。
- 空字符串、非法 model 引用、无效 team 形状和非正数 timeout 等不可消费值拒绝。
- 未知键按当前工具契约处理。
- 形状表完备性可检查，但验证以工具行为为主。

### 2.7 输出

普通值显示 `key = value (type)`，数组类型显示 array。set 回执说明 persisted 与 hot-applied 的实际含义；需要后续读取或重启的键不得被描述为所有运行行为已即时改变。

### 2.8 多端

各端使用同一 core 工具工厂与写链。端侧只提供 live config 载体和宿主界面。

端侧载体没有某配置段时，写盘仍可成功；回执必须遵守该端实际消费时机。

### 2.9 失败与边界

形状校验只拒绝应用侧无法消费的形态。外部渠道、模型、命令是否真实存在由各自运行面检查。

写入验证使用隔离配置路径，写侧工厂与读侧测试缝必须指向同一临时文件。

## 3. 关键决策

| # | 决策 | 理由 |
|---|---|---|
| D-ST1 | 支持当前配置域而非硬编码短白名单 | 避免新增键被工具无故遗漏 |
| D-ST2 | 单工具多动作 | 保持工具面稳定 |
| D-ST3 | 写盘与 live 更新都显式 | 防止重启丢失或假热应用 |
| D-ST5 | null 形状显式建表 | 默认值 null 无法提供类型信息 |
| D-ST6 | 不可消费值在写入时拒绝 | 防止“写了但读取时悄悄回退” |
| D-ST8 | 错误文本也遮蔽 | 错误路径同样可能泄漏凭据 |
| D-ST9 | 形状层不校验外部存在性 | 可达性属于业务运行面 |
| D-ST13 | headers 与 env 整族遮蔽 | 开放键名无法靠词表穷尽 |

## 4. 验证

- list/get/set 的实际工具行为。
- 点路径、数组、缺失和 null。
- 值解析与不可消费形态。
- 写冲突与磁盘、内存零假变化。
- 敏感键、开放族、父对象和错误文本。
- 派生视图与端侧实际生效时机。
- 工具描述只作为使用契约核对，不用文本命中替代行为验证。
