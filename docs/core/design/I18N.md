# 文案与本地化（I18N）· 设计

> 需求 = `docs/core/requirements/I18N.md`。
> 最近先例：`CORE-UNIFICATION.md` 的端差注入。对齐 = 核内容单源，宿主容器可不同。
> 勘察证据：已读核字典投影与 VSC 本地键叠加。相关 = 当前文案容器。

## 1. 核容器

core 文案表以 key 为身份，携带当前中英文文本。共享业务文案只在这里撰写。

## 2. 宿主投影

VSC 的 projectDictionary 把核值投影到 t() 字典，端侧 locales 只叠加宿主/webview 特有键。

CLI 等可直接引用核导出，不为形式一致引入第二字典。

端侧不得再复制核域同值键；需要覆盖同 key 时先确认它确属端特有语义。

## 3. 契约边界

[error] 前缀、ACP 协议文本、VSC 既有 key 与机器事件不因容器变化而改变。

人读文案调整时同步字典、界面和测试。内部提示词文本由 PROMPT-SYSTEM 负责，不混入本字典。

## 4. 验证

验证同 key 同值、端特有键可用、缺键可读、协议字符串不变和无核域重复副本。
