# 多实例协作（MULTI-INSTANCE-COLLAB）· 需求

> 设计 = `docs/core/design/MULTI-INSTANCE-COLLAB.md`；会话 = `SESSION.md`。

## 1. 感知

- 同 cwd 的活跃实例可被自动提醒和 peer_instances 只读查询。
- 查询过滤自身，字段仅 pid/end/sessionId/slots。
- 判活批量、有界、尽量异步；进程号复用时用产品身份复核。
- 探测未知时，认领/清理保守保留；展示面可按当前规则降级。
- 感知不认领槽、不写 manifest。

## 2. 文件域软避让

- 结构化写成功后登记当前实例的写足迹与意图 claims。
- 新目标及时落盘，同域续约按当前节流，租约到期或属主死亡后失效。
- 写前命中其他活实例的热足迹或有效 claim 时附软提示，写不被阻止。
- claims 是弱信号，不是锁；足迹与 claims 分字段合并，互不覆盖。
- bash 等任意命令通道不宣称被完整观测。

## 3. 配置并发

共享 config.json 写入在新鲜盘面执行单操作，写前检查 mtime。冲突时保全现场、放弃本次写并提示重试，不用旧内存快照覆盖。

## 4. 跨实例消息

- instance_list 列出本机可投递会话；instance_send 向指定 sessionId 非阻塞发送。
- 跨 cwd 可寻址，但只有装配了取件面的会话入册。
- 发送前验证名册、pid 活和 inbox 可写；失败当场报错。
- 回执 delivered-to-inbox 只表示落盘，不表示已读或已处理。
- requestId 与 re 用于对账，不形成任务从属或待办。
- 忙碌 = 已有一轮在飞。等待后台子代理结果不算忙碌，取件不因它推迟。
- 目标忙碌时消息留在 inbox，当前轮结束后由下一拍起新轮；等待期在状态栏可见待取条数。
- 取件一次性，开轮失败和长期受阻必须在目标端可见。
- 不提供离线持久队列、广播、订阅或跨机器投递。

## 5. 验收

验证身份与三态、批量探测、软提示不阻断、claims 续约/过期、配置 mtime 冲突、发送负例、非阻塞、忙碌（一轮在飞）不取件、挂起窗内照常取件、一次性取件和失败可见。
