# 工具系统（TOOLS）· 需求

> 设计 = `docs/core/design/TOOLS.md`；输出预算 = `TOOL-OUTPUT-LIMITS.md`。

## 1. 通用契约

- 注册表可枚举，schema、描述、执行门和角色可见性一致。
- 描述说明用途、参数、路由、副作用、错误和限制。
- 工具结果有界，全文可回查；console 捕获有界并进入结果。
- 权限、快照和业务门按真实副作用执行，不靠命令文本伪造安全。
- 配置键必须有消费点和设置 UI。
- 端壳只保留宿主能力差异。

## 2. 文件与命令

- 路径相对会话锚或绝对路径；写权由当前项目/批次规则决定。
- **F16 · edit 批量逐条成败**：按条目报告，失败不掩盖其他条已写结果；同档合并写。
- apply_patch 等批量写使用同一失败骨架。
- delete/file_ops/git 等按当前可逆与审批规则。
- bash 支持当前同步/异步、日志、超时与进程树终止；长任务不阻塞会话。
- execute 是真实 Node ESM 子进程，不是伪沙箱。
- git 缺省发现当前项目仓，零/多候选不猜；所有交互与 pager 被压制，超时可见。

## 3. 角色与模式

- depth>0 不提供 question/ssh 等需要活人窗口的工具。
- 工程模式 task 不使用，追踪由批次与 ledger 承担。
- tester 获得只读工具与 execute/bash，可创建运行验证所需的临时夹具；不得修改实现、文档、既有测试或断言，不写批次或台账，报告列出实际写入位置。
- execute/bash 能写文件和执行真实命令；tester 的「只跑不改」是角色纪律，不是文件系统隔离或安全沙盒。
- 只读角色获得当前允许的 action 级查询，不看到不可执行写说明。

## 4. 网络

websearch/fetch 按当前 MCP 优先、DeepSeek/Tavily/Bing/local 后端规则工作。私网与元数据地址拒绝。

DeepSeek 官方渠可自动提供搜索/抓取；显式 backend=local 跳过。后端失败按当前有界重试和回落，404 不触发凭据熔断。

## 5. SSH

ssh 提供长命交互会话、密钥优先、可选系统加密凭据、凭据清单/删除，以及单文件 put/get。

密码通过结构化窗口直达子进程，不进模型、消息或日志。设备交互有待答标记、硬超时和输出上限。

put/get 二进制安全；get 不覆盖现存本地文件、不自动创建父目录并遵守当前写门。不支持全屏终端编辑器和递归目录同步。

## 6. 资源

read 分页与当前双端返回；普通工具输出超过 64K 落盘并给头尾预览；报告按 TIMEOUT-DIGEST。

write 后运行当前 lint；verify 不代跑测试。网络响应、捕获、索引和后台任务都有当前上界。

## 7. 验收

验证注册/角色矩阵、权限负例、路径、批量部分失败、异步生命周期、git 非交互、网络回落、SSH 凭据与传输、输出全文可达。
