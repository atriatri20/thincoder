# 文案与本地化（I18N）· 需求

> 设计 = `docs/core/design/I18N.md`。

## 1. 目标

共享业务文案由 core 提供同一语义，宿主按自身呈现与本地化机制消费。端侧只保留真正端特有的文案。

## 2. 功能需求

- 核文案容器以稳定 key 管理中英文值。
- VSC 可通过 projectDictionary 与 t() 消费核字典，并叠加端特有键。
- CLI/Desktop 等可直接使用核常量，不强制引入相同字典壳。
- 同一 key 不在核与端侧维护两个同义副本。
- 缺键行为符合各宿主当前可读降级，不静默显示空白。

## 3. 契约

机器消费的前缀、协议文案、事件字段和既有 locale key 不随容器归一静默改变。

人读文案变化同步负责文档、字典和相关测试；需要用户裁定的行为变化仍逐项提交。

## 4. 验收

验证核字典投影、端特有叠加、缺键回退、机器文案不变和跨端同语义。
