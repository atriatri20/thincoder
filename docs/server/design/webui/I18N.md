> 壳 = `WEBUI.md`。
> 最近先例：VSC/Desktop 静态词表与 core t()。对齐 = 静态 ESM、缺键可见、错误码映射。
> 勘察证据：已读检测、切换、复数、错误和按域拆表。相关 = 当前 i18n。

## 1. 语言与词表

zh/en 由 i18n-zh.mjs 与 i18n-en.mjs 聚合域部件。localStorage 记忆优先，否则按 navigator.languages，未匹配回 zh。

t(key,params) 插值，缺键按当前表→中文→键名并警告；英文计数可用 Intl.PluralRules 的 .one 变体，中文不强制复制。

## 2. 切换与错误

侧栏和登录卡的显式切换更新记忆、document.lang 并重渲；render-core 的 setStrings 同拍重注册。

控制台按 err.<code> 映射当前 API 错误，Retry-After 可插值，未知码保留服务端原文，网络失败给人话。

## 3. 验证

验证两表基键闭合、占位符、英文复数、检测/切换、错误映射、键引用和 en 运行文案无意外中文。
