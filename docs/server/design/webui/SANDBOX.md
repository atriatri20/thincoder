# Server 沙盒页面 · 设计

> 控制机制 = `../sandbox/SANDBOX.md`；执行 = `../sandbox/EXECUTION.md`；tabs/terminal = `TABS.md`、`TERMINAL.md`。
> 最近先例：公共弹窗与资源表。对齐 = 节点面可用、真实状态门、失败保稿。
> 勘察证据：已读运行、容器、镜像源、卷、工作区、底座、凭据和终端。相关 = 当前沙页面。

## 1. 管理面

#/admin/sandbox 分运行与镜像/源标签。运行面含节点、容器、卷、工作区、资源/TTL 和审计入口；无 runner 不阻止节点登记。

容器动作按运行态禁用并防连点，完成回到新状态；删除节点并行读取容器与承载，读失败不能当无承载。

## 2. 镜像、底座与凭据

镜像拉取/删除、源目录/标签与预填、卷选择/删除、底座设置/派生和私有凭据均走真实 API，失败就地显示。

TLS/SSH/registry 秘密零回填，切回明文和删除有确认。容器终端仅运行中可开，使用真 PTY 核件，关窗收口。

## 3. 成员工作区

#/me/sandbox 恒本人过滤，显示盒状态、停因、快照和 runner；按当前成员权限提供创建、启动、停止、销毁和拉仓入口，不能只读冒充完整自管面。

## 4. 验证

验证标签保活、状态/忙态、删除负例、拉取/卷、TLS 秘密、成员隔离与真实终端。
