# Server 团队台账页面 · 设计

> 机制 = `../ledger/LEDGER.md`；壳 = `WEBUI.md`。
> 最近先例：项目页权限感知与公共 modal。对齐 = 全员同一页、后端能力真值。
> 勘察证据：已读列表三筛、新建编辑、收口撤回与键族。相关 = 当前团队账页。

## 1. 页面

#/me/ledger 显示全局编号、仓、标题、状态/老化、负责人、更新和动作，按 repo/status/owner 筛选。

新建仅从可写项目选择仓；详情编辑仅在 canWrite 时显示，状态选项来自合法后继，仓不可改。

## 2. 收口与撤回

保存经 PATCH，失败留窗可重试；已核销只从待核销收口，其他态的服务端拒绝就地显示。

撤回使用非原生确认，说明软删后果。页面不承载本机账或自动同步。

## 3. 验证

验证筛选、权限显隐与直打、状态负例、新建、编辑、收口、撤回和审计随动。
