# Server 我的页面 · 设计

> 壳 = `WEBUI.md`；账号与用量 = `../accounts/ACCOUNTS.md`、`../metering/METERING.md`。
> 最近先例：公共弹窗、管理用量表与接入卡。对齐 = 本人数据、同源构件、无假导出。
> 勘察证据：已读 key 工作台、用量图表与 Git 凭据卡。相关 = 当前我的面。

## 1. Key

#/me/keys 显示具名多把 key、签发/最后使用/近 30 天和逐把吊销。签发/吊销用 modal，明文只在一次性区域显示并可复制，接入卡复用系统构件。

页面没有轮换按钮；`POST /api/me/keys/rotate` 虽保留为全换 API，但会吊销本人全部 active key、新签一枚默认名 key，且非事务、旧标签不保留。UI 以签发新 key 和逐把吊销为唯一操作面，不得给该 API 暗示单把或保名轮换入口。

## 2. 用量

#/me/usage 以同一时间/端点/模型筛选同时读取 summary 与明细，显示本月概览、KPI、按日堆叠柱、分模型和明细。

数据由服务端零填充和本人过滤，图表纯 CSS，不引入库；无金额和本人导出面。

## 3. 账户与 Git 凭据

账户页展示本人信息并支持改密。Git 凭据卡按主机增改删，秘密只写不回显；拉取流内录入复用同一 API。

## 4. 验证

验证多把、一次性秘密、复制失败、无全换按钮、筛选同拍、空/错态、图表无外部依赖和凭据零回显。
