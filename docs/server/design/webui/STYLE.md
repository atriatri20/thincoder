# Server 样式与版式 · 设计

> 壳 = `WEBUI.md`；终端例外 = `TERMINAL.md`。
> 最近先例：Desktop 排版基线与控制台既有类名。对齐 = 单源变量、统一交互态、不重造骨架。
> 勘察证据：已读列表/按钮/表单/字排/色板/弹窗和视口壳。相关 = 当前样式面。

## 1. 样式

style.css :root 统一色、间距、圆角、字排、线宽和布局，render-core 变量通过根级别名映射，不复制颜色值。

列表、按钮、表单、卡片、弹窗、空/错/加载和码面使用同一状态语言；可点行有指针、焦点环和键盘入口。

[hidden] 必须真实 display:none，任何布局类不得复活隐藏面。终端 cell 的粗体和 ANSI 调色板按 PTY 语义例外。

## 2. 数据表布局

数据表页使用页头、可伸缩表区、吸附表头和真实 tfoot 计数；窄/矮视口按当前回退整页滚。

弹窗内长表在自身滚区滚动，主内容左对齐；图表页和对话页按各自结构，不强套数据表壳。
