# Server 系统页 · 设计

> 壳 = `WEBUI.md`；配置 = `../ops/OPS.md`；公网 = `../gateway/PUBLICNET.md`。
> 最近先例：server 配置读写与真实诊断。对齐 = 所见即所存/所测、重启生效明示。
> 勘察证据：已读版本、接入、向量、服务配置、代理和健康。相关 = 当前系统页。

## 1. 页面

#/admin/system 含版本/更新、成员接入、向量服务、服务配置和健康；侧栏 meta 向全角色显示版本与健康。

接入卡含当前 origin 的 /v1、key 签发入口、客户端示例和 curl；成员 key 页复用同构件。

## 2. 配置与向量

服务配置读 config 有效值，拓扑项只读，可写项按白名单 PATCH，非法零写，统一标重启生效。TLS/限流等当前配置同样进入本面。

向量卡可编辑 baseURL/model/key，掩码不当作新秘密；未配置不自动探活，保存可创建配置段。草稿探活和试跑返回真实维度/时延/错误。

## 3. 代理测试

proxy.uri 与保存同卡，测试以表单 uri 和目标真发请求，读 HTTP 状态和耗时，传输失败分类，空值就地拒。

诊断不落用量或计费，旧代理路由重定向到系统页。

## 4. 验证

验证配置往返、秘密掩码、缺段、草稿探活、代理真打、更新读数与健康共享。
