## 1. 清单

#/admin/mcp 显示名称、stdio/http/ws、无秘密 target、启用和探活/改/删。启用即时写，失败回读。

增改共用 modal，按传输显示 command/args/env 或 url/wsUrl/headers/token；秘密零回填，留空不变，显式清除才 null。

## 2. 探活与删除

行内探活使用库 id，弹窗测试使用当前草稿，结果含真实工具名/计数/时延或错误，不改库。

删除用公共确认，说明工具将退出会话；失败保稿，提交在飞防重复。
