# Server 项目与 Git 源页面 · 设计

> 机制 = `../project/PROJECTS.md`；壳与 tabs = `WEBUI.md`、`TABS.md`。
> 最近先例：权限感知项目弹窗与公共 tabs。对齐 = 单入口、同构件、服务端判权。
> 勘察证据：已读我的项目、管理双标签、加仓与 Git 源表单。相关 = 当前项目面。

## 1. 项目

#/me/projects 只列本人可见项目，搜索并开权限感知详情；按 can 控制成员、显示名、地址、负责人和删除控件，后端仍强制。

#/admin/projects 以项目/Git 源两标签承载管理，子段进地址，旧 git-sources 别名落第二标签。添加仓支持源列表批量选择与手输，重复和失败就地显示。

## 2. Git 源

源表显示平台、PAT 掩码、启停、同步方式、上次结果和操作。手动同步恒在，拉列表和体检复用同一源上下文。

添编弹窗按平台显示基址、scope、gitee 三态与事件配置；非自建基址真隐藏，事件仅支持的平台可选。PAT/webhook 秘密零回显，新秘密一次显示。

## 3. 验证

验证可见性、能力负例、标签与旧链、批量全成/全拒、范围条件、PAT 失效和删除确认。
