## 1. 对象与能力

项目与仓一对一，源持平台/范围/PAT/同步配置。用户名对接成员，手工行优先于同步行。

项目详情返回 `my.can`，UI 只按它显示操作控件，后端仍以同一 capabilitiesOf 判定。团队账只消费其中的 can.view/can.write，不另建角色映射。

| 身份/档位 | can.view：项目与团队账读 | can.write：团队账写 | manageMembers | rename | editAddress | 换负责人 | delete |
|---|---|---|---|---|---|---|---|
| admin | 是 | 是 | 是 | 是 | 是 | 是 | 是 |
| owner（负责人） | 是 | 是 | 是 | 是 | 否 | 否 | 否 |
| manage | 是 | 是 | 是 | 否 | 否 | 否 | 否 |
| readwrite | 是 | 是 | 否 | 否 | 否 | 否 | 否 |
| read | 是 | 否 | 否 | 否 | 否 | 否 | 否 |
| 非成员且非负责人/admin | 否 | 否 | 否 | 否 | 否 | 否 | 否 |

非成员列表不见且直取 404；可见但无相应能力才返回 403。负责人不可被非 admin 移除或降档，地址修改、换负责人和项目删除仅 admin。

## 2. 平台与同步

gitee 显式个人/组织/企业，github、gitlab 与自建 GitLab 兼容按各自 API 拉仓和名册；失败如实分类，不自动换范围。

PAT 用共享 AES 凭据件，界面零回显。同步为手动、定时和可用事件三径；平台角色映射当前三档，单事务应用，manual 不覆盖，名册截断时禁止删除。

github webhook 以每源秘密验签后触发全量对账，事件模式仍定时兜底；客户端不写回平台。

## 3. 生命周期

加仓支持批量选择与手输，地址归一防重复。停用源停定时但保项目，仍挂项目时拒删源。

项目删除需 confirm，同事务删成员并审计。同步结果、PAT 体检、来源和 actor 均可查。

## 4. 验证

验证能力矩阵负例、地址归一、四平台假件、单向同步、截断、验签、并发锁和删除事务。
